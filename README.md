# Library Management System

Application developed in C# using a layered architecture to manage library operations such as book registration, user management, and loan tracking.

---

## Technologies

* C#
* .NET
* SQL Server
* Layered Architecture (Presentation, Business Logic, Data Access)

---

## Features

* Book registration and management
* User management
* Book loan and return system
* Database integration with SQL Server

---

## Architecture

This project follows a **layered architecture**, separating concerns into:

* Presentation Layer
* Business Logic Layer
* Data Access Layer

This approach improves maintainability, scalability, and code organization.

---

## Security Considerations (Basic)

Although this is an academic project, some important aspects to consider include:

* Input validation to prevent incorrect data handling
* Proper database query handling (avoid SQL injection)
* User data management practices

---

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/your-username/library-management-system.git
```

2. Open the project in Visual Studio

3. Configure the database:

* Execute the provided SQL script in SQL Server
* Update the connection string in the project

4. Run the application
